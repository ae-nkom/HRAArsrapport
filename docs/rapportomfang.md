# Avgrensning mot oppdraget

Gjennomgått mot den lokale e-posten, den vedlagte årsrapporten og utregningsgrunnlaget. Kildene er interne og ligger utenfor publiseringsbygget.

| Behov i grunnlaget | Leveranse i appen |
| --- | --- |
| Lønnsuttrekk per 1. mai eller 31. desember | Valg av eksakt dato og år under Datagrunnlag |
| Stillingsgrupper etter utregningsskjemaet | Gruppeinndeling med eksplisitt avklaring av tvetydige roller |
| Kjønnsbalanse per gruppe | Antall og andeler, med samme kolonnerekkefølge som rapportmalen |
| Gjennomsnittlig fastlønn, overtid og vakttillegg | Rapporttabeller med kvinner, menn, totalt og kvinners gjennomsnitt i prosent av menns |
| Midlertidige ansatte og faktisk deltid | Antall og andeler per kjønn |
| Foreldrepermisjon | Antall med uttak, gjennomsnittlige uker og andel av permisjonsdagene |
| Nyansettelser og sykefravær | Fire manuelle felt som følger med Word-eksporten |
| Historikk for rekruttering og inkludering | Redigerbar tabell for rapportåret og de fem foregående årene |
| Inkludering, utdanningssamarbeid, ARP og faglige forklaringer | Egne deler i Word-utkastet, som ferdigstilles manuelt |

## Hva lønnsprosenten betyr

Kolonnen «Kvinner i % av menn» inngår uttrykkelig i rapportmalens tabeller for fastlønn og variable tillegg. Den skal derfor beholdes. Tallet er kvinners gjennomsnitt dividert med menns gjennomsnitt i samme gruppe, ganget med 100.

Malen ber ikke om automatisk rangering av den største prosentforskjellen eller om at en bestemt gruppe skal løftes frem som appens hovedfunn. En slik rangering kan fremheve små eller uavklarte utvalg. Disse kortene og de automatisk genererte forklaringskravene er fjernet. Faglige vurderinger må bygge på det avklarte grunnlaget.

## Hva som er fjernet fra hovedflyten

Kostnadstopper, månedsutvikling, spredningsdiagrammer, deltakelsesgrafer per gruppe, varmekart og automatiske «hovedfunn» er ikke nødvendige for leveransen i vedlegget. Sidene viser nå rapporttabellene først, og et begrenset antall diagrammer av de samme tallene. Rådata, gruppevalg og koblingskontroller er fortsatt tilgjengelige.

Visningsendringene endrer ikke beregningsmetodene. Kjente forskjeller mellom rådata og tidligere rapporttekst håndteres fortsatt som datakontroll, ikke ved å overstyre resultatene med historiske tall.
